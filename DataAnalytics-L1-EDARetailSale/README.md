# Retail Sales Data Analysis

## Project Overview

This project analyzes retail sales data to identify sales trends, customer behavior, and product category performance.

## Dataset

The dataset contains 1,000 retail transactions with information about:

- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Kaggle Notebook
- GitHub

## Analysis Performed

- Data cleaning and validation
- Overall sales analysis
- Sales by product category
- Monthly sales trend analysis
- Sales by gender
- Sales by age group
- Top 10 customers by spending
- Product category and gender analysis

## Key Insights

- Total Sales: ₹456,000
- Total Transactions: 1,000
- Total Quantity Sold: 2,514
- Average Transaction Value: ₹456
- Electronics generated the highest sales: ₹156,905
- Clothing had the highest quantity sold: 894 units

## Conclusion

The analysis provides insights into customer purchasing behavior, product performance, and sales trends. These insights can help businesses understand their best-performing products and customer segments.
