# Data Analytics Level 1 - Task 2: Customer Segmentation

## Project Overview

This project segments customers based on their purchasing behaviour using RFM analysis and K-Means clustering.

## Dataset

The Online Retail II dataset contains transaction-level customer purchase information.

The analysis uses:

- Customer ID
- Invoice
- Invoice Date
- Quantity
- Price
- Country

## Methodology

The project follows these steps:

1. Data loading and inspection
2. Data cleaning
3. Descriptive statistics
4. Transaction value calculation
5. RFM feature creation
6. Feature standardization
7. Elbow Method for selecting the number of clusters
8. K-Means clustering
9. Cluster profiling
10. Cluster visualization
11. Business recommendations

## RFM Analysis

RFM represents:

- **Recency:** How recently a customer made a purchase
- **Frequency:** How frequently a customer purchases
- **Monetary:** How much a customer spends

## Customer Segments

Four customer segments were identified:

- **High-Value Customers**
- **Loyal Customers**
- **Regular Customers**
- **At-Risk / Low-Value Customers**

## Business Recommendations

- **High-Value Customers:** Provide VIP rewards, exclusive offers, and personalized recommendations.
- **Loyal Customers:** Use loyalty programs and personalized promotions to maintain engagement.
- **Regular Customers:** Encourage increased purchase frequency through targeted promotions.
- **At-Risk / Low-Value Customers:** Use re-engagement campaigns, discounts, and personalized offers.

## Conclusion

RFM analysis combined with K-Means clustering provides a useful approach for understanding customer purchasing behaviour and developing targeted marketing strategies.
